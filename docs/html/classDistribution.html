Detailed Description

Класс для расчета и хранения теоретических вероятностей распределения Пуассона.

Класс автоматически вычисляет и кэширует значения вероятностей (PMF) и кумулятивных сумм (CDF) распределения Пуассона для оптимизации повторных запросов.
