\hypertarget{index_autotoc_md6}{}\doxysection{\texorpdfstring{Функциональные возможности программы}{Функциональные возможности программы}}\label{index_autotoc_md6}
\hypertarget{index_gen_sec}{}\doxysection{\texorpdfstring{1. Моделирование пуассоновских выборок двумя методами}{1. Моделирование пуассоновских выборок двумя методами}}\label{index_gen_sec}
Программа позволяет генерировать псевдослучайные последовательности с заданным параметром интенсивности $\lambda$ двумя принципиально разными путями\+:
\begin{DoxyItemize}
\item {\bfseries{Метод обратной функции}} (реализован в классе \doxylink{classPoisGenInvFunc}{Pois\+Gen\+Inv\+Func}) — моделирование через последовательное суммирование вероятностей и сравнение с CDF.
\item {\bfseries{Алгоритм Кнута}} (реализован в классе \doxylink{classPoisGenKnuth}{Pois\+Gen\+Knuth}) — моделирование на основе подсчета числа событий в простейшем потоке через произведение равномерных случайных величин.
\end{DoxyItemize}\hypertarget{index_stat_sec}{}\doxysection{\texorpdfstring{2. Статистический анализ критерием Хи-\/квадрат Пирсона}{2. Статистический анализ критерием Хи-квадрат Пирсона}}\label{index_stat_sec}
Для проверки гипотезы о соответствии сгенерированной выборки теоретическому закону Пуассона в программе реализован класс \doxylink{classChiSq}{Chi\+Sq}, выполняющий\+:
\begin{DoxyItemize}
\item Автоматическое вычисление и кэширование теоретических вероятностей (класс \doxylink{classDistribution}{Distribution}).
\item Группировку малочисленных смежных интервалов по правилу $n \cdot p_i \ge 5.0$ для обеспечения корректности аппроксимации.
\item Расчет эмпирического значения статистики $\chi^2$, числа степеней свободы $df$ и значения $p\text{-value}$.
\item Построение интерактивных {\bfseries{гистограмм частот}}, наглядно сопоставляющих наблюдаемые (эмпирические) и ожидаемые (теоретические) частоты попадания в интервалы.
\end{DoxyItemize}\hypertarget{index_pval_sec}{}\doxysection{\texorpdfstring{3. Исследование распределения p-\/value и мощности критерия}{3. Исследование распределения p-value и мощности критерия}}\label{index_pval_sec}
Программа предоставляет мощный функционал для визуализации и анализа поведения статистического критерия\+:
\begin{DoxyItemize}
\item Построение графиков {\bfseries{эмпирической функции распределения p-\/value}} при справедливости нулевой гипотезы $H_0$ (параметры генератора и гипотезы совпадают). При этом график автоматически сопоставляется с эталонной функцией $F(x) = x$, так как при $H_0$ величина $p\text{-value}$ должна быть распределена равномерно на отрезке $[0, 1]$.
\item Построение графиков распределения $p\text{-value}$ при альтернативной гипотезе $H_1$ (когда реальная интенсивность генератора отличается от гипотетической). Это позволяет визуально оценить и рассчитать {\bfseries{мощность критерия}} при заданном уровне значимости $\alpha$.
\end{DoxyItemize}\hypertarget{index_perf_sec}{}\doxysection{\texorpdfstring{4. Анализ вычислительной эффективности (Зависимость времени от лямбда)}{4. Анализ вычислительной эффективности (Зависимость времени от лямбда)}}\label{index_perf_sec}

\begin{DoxyItemize}
\item Измеряется чистое время генерации массивов больших объемов в миллисекундах.
\item Строятся \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}графики зависимости времени моделирования от параметра $\lambda$\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*} одновременно для обоих методов.
\end{DoxyItemize}
