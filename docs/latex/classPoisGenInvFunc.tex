\doxysubsection{Detailed Description}
Класс-\/генератор пуассоновских случайных величин методом обратных функций. 

Данная реализация использует моделирование случайной величины через кумулятивную функцию распределения (CDF). Алгоритм генерирует случайное число $\alpha \in [0, 1)$ и последовательно перебирает значения $k$, пока $\alpha$ не окажется меньше или равно значению кумулятивной суммы $F(k)$.
\begin{DoxyItemize}
\item \begin{DoxyNote}{Note}
Этот метод эффективен при небольших значениях лямбда ( $\lambda$), однако при росте интенсивности среднее число итераций цикла увеличивается линейно ( $M[k] = \lambda$), что может снижать производительность. 
\end{DoxyNote}

\end{DoxyItemize}
