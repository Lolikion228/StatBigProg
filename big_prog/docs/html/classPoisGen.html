Detailed Description

Абстрактный базовый класс для генераторов случайных величин, распределенных по Пуассону.

Определяет общий интерфейс генерации единичных значений и накопления массивов выборок. Объекты _dist и _stdgen являются внешними ресурсами и не уничтожаются данным классом.
