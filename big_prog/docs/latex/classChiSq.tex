\doxysubsection{Detailed Description}
Класс для проведения статистического анализа соответствия критерию Хи-\/квадрат Пирсона. 

Рассчитывает эмпирические и теоретические частоты на основе выборки генератора и проверяет нулевую гипотезу о соответствии пуассоновскому распределению.
